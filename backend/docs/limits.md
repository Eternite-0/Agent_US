# 支持范围与已知限制

| 边界 | 当前行为 |
| --- | --- |
| 部署 | 已验证 Windows 主机、Docker Desktop 的 Linux amd64 引擎和 Node 24。HTTP API 使用单个服务令牌并监听回环，适合单用户或受信任团队网关。多租户身份、RBAC、分布式数据库和跨主机高可用属于后续工作。|
| Provider | 已验证 OpenAI Chat Completions 文本、工具流和 Magpie 路由，供应商侧使用确定性 HTTP 模型。真实付费账户、不同供应商的 reasoning 扩展和多模态输入尚待用实际账户验收。流开始后的失败记录为失败尝试。|
| 沙箱 | 依赖受信任的 Docker 服务及管理员构建的镜像。Codex 的内层 RPC 配置为在已隔离的容器中执行，安全边界由容器施加。Worker 网络策略目前为断网。研究类角色可分析提供的上下文和产物。带域名白名单的联网检索尚未交付。|
| 工作区 | 通过可携带的相对路径传递文件，单文件上限 64 KiB，一个工作快照最多 64 个文件、256 KiB。文件名接受字母、数字、点、横线、下划线和斜杠。Git 目录可在同一尝试的工具调用之间传递，发布时过滤。目录权限、可执行位和链接不在产物格式内。|
| PTY / MCP | 支持有时限的 TTY 命令及输出捕获，MCP 支持预配置程序的 stdio `initialize` 和 `tools/call`。交互式终端的长期附着与调整窗口、MCP OAuth 和远程 transport 尚未交付。|
| 恢复 | 已提交的节点结果保持有效。在途节点从新 Session 开始，保留旧会话历史并重新审批。该协议提供分派级恢复。模型流、正在运行的进程及未发布的内存快照无法逐 token 续接。|
| 上限和计费 | 单次命令软超时 8 秒，容器内 12 秒硬期限，宿主另设外层期限。模型每次尝试默认最多 8 个请求。费用采用供应商上报 usage 计算，已发出的并发请求可能使实际费用超过估算阈值。模型质量评分和价格由运营者提供。|
| 持久化 | 项目记忆来自最近三项验收结论，压缩采用可辨认摘要边界及原文哈希。历史查询保留有界文本投影，完整文件产物单独保存。长时间部署需要按保留策略归档历史与证据。|
| 构建 | npm 依赖、DSH/Codex/Magpie 版本和镜像基础摘要已锁定。构建时 Git 由 Debian 仓库安装，补丁版本随仓库移动。完整构建需要访问 npm、GitHub、镜像和 Debian 仓库。|

## 2. Empirical Bottlenecks in Agent_US Baseline (`b50da9b`)

Direct inspection of `b50da9b` identifies five structural bottlenecks in autonomous reasoning that do not stem from the Codex tool layer:

1. **Narrow Loop/Stuck Detection (`backend/src/kernel/agent-loop.js`)**
   - `TurnManager.recordToolSignature` (`L144-159`) keeps only the last 6 `(toolName, args, isError)` SHA-256 digests and triggers `LOOP_THRASHING_WARNING` at `>= 3` identical signatures.
   - **Blind spots:** alternating ping-pong cycles (`A -> B -> A -> B`), repeated failures with slightly varied arguments (`same_error_streak`), edit-then-fail cycles without intermediate inspection (`edit_test_fail_loop`), and no normalized error fingerprinting or falsified-attempt ledger to guide the model's pivot.

2. **Pass-Claim-Gated Post-Edit Verification (`backend/src/governance/verifier.js`, `backend/src/verifier.js`)**
   - `EvidenceVerifier.verify()` (`L251-262`) only raises `FABRICATED_PASS_CLAIM` when `PASS_CLAIM_RE` matches assistant prose while `findUnresolvedVerification` finds a failing command.
   - **Bypass modes:**
     - *Stale verification:* if tests pass early in a turn and a later `write_file`/`edit_file`/`apply_patch` mutates code, `latestShell` still has `exitCode === 0`, so `b50da9b` accepts unverified post-edit mutations (`STALE_VERIFICATION_AFTER_EDIT` missing).
     - *Silent failure exit:* if tests fail and the model stops with neutral prose avoiding `PASS_CLAIM_RE` (or emits JSON without pass phrases), `UNRESOLVED_VERIFICATION_FAILURE` is not triggered unless `evidenceContract` explicitly fails.

3. **Unstructured Stage-1 Pruning & Anchor Gaps (`backend/src/context.js`, `backend/src/context/compaction.js`)**
   - `compactTwoStage` prunes message text via generic head/tail truncation without deduplicating superseded `read_file` payloads for the same normalized path or prioritizing stack traces/assertion failures.
   - `MultiStageCompactor.extractTaskStateAnchor` (`L34-100`) captures `goal` (600 chars), `constraints`, `activePlan`, `modifiedFiles`, and raw `receipts`, but does not preserve a structured `verificationLedger` or `falsifiedAttempts` across compaction boundaries.

4. **Degenerate Replan Tolerance (`backend/src/planning/replanner.js`, `backend/src/swarm/replan.js`)**
   - `AdaptiveReplanner.replan` (`L36-91`) enforces `assertBudgetNotInflated` and completed-task/side-effect immutability, yet permits no-op replans that repeat the identical objective and strategy after failure (`PLANNER_DEGENERATE_REPLAN_DENIED` missing).
   - `DynamicReplanner.diagnoseWithModel` (`backend/src/swarm/replan.js`) passes minimal error strings without aggregating full `tool_receipts` or prior `swarm_replans` history.

5. **Open Experience Learning Loop (`backend/src/memory/service.js`, `backend/src/direct-agent.js`, `backend/src/evaluation/service.js`)**
   - `ExperienceMemoryService` already enforces fail-closed `#verificationAuthority` and `createTrustedVerifier()`, and `ContextAssembler.assemble()` already queries it (`L175-177`).
   - However, `b50da9b` lacks automatic turn distillation (`distillTurnExperience`) from verified evaluation outcomes vs candidate-only (`verified: false`) direct turns, and `rank()` lacks file-path / error-signature affinity signals.

Agent_US 2.4 strictly preserves the Codex-owned Layer 4 & Prompt Cache substrate shipped in 2.3.4–2.3.7:

- **Untouched Codex-owned modules:**
  - `backend/src/tools/selection.js` (`modelToolCatalog`, `selectionRecoveryHint`)
  - `backend/src/tools/policy.js` (`ToolPermissionPolicy`, `intersectPolicies`)
  - `backend/src/tools/dispatcher.js` (`ToolDispatcher`, `ToolResultProcessor`)
  - `backend/src/tools/builtin/fs-tools.js` (`createFsTools`, `readFileState` anti-stale guard)
  - `backend/src/repo-intelligence.js` & `backend/src/repo-symbols.js`
  - `backend/src/observability/prompt-cache.js` (`stableTools`, `normalizeProviderUsage`, `observeProviderUsage`)
- **Preserved System Invariants:**
  - `buildStaticSystemPrompt(nonce)` (`backend/src/agent-context.js`) remains byte-identical across turns; dynamic state (experience memory, compaction anchor, plan state) enters strictly via `liveContextNotes` tail messages (`ContextAssembler`).
  - `ToolDispatcher` permits, `approvalId`/`argsDigest` binding, and `BenchmarkSandbox` Docker strong OS isolation (`--network=none`, `--read-only`, `--cap-drop=ALL`, `--user=65534:65534`, fail-closed) remain unmodified.
  - `ExperienceMemoryService.#verificationAuthority` cannot be bypassed by Direct turns (`verified: false` candidate-only); only `EvaluationService` runs backed by `enforceDeterministicHardVeto` + `createTrustedVerifier()` promote `verified: true` patterns.

Implemented in `backend/src/evaluation/autonomous-reasoning-benchmark.js` and `backend/scripts/benchmark-autonomous-reasoning.mjs`:

All 10 judges verify git baseline/test integrity (`verifyWorkspacePinnedBaseline`, `listWorkspaceChangedFiles`, frozen baseline SHA-256 hashes), run inside fail-closed `BenchmarkSandbox` (Docker default), execute `runHiddenAcceptance`, and enforce `enforceDeterministicHardVeto` (zero advisory/premature-exit bypass).

### 4.2 Nine-Metric & Three-Way Attribution Model

`computeAutonomousReasoningMetrics(trials)` retains 100% of failed/timed-out/cancelled trials and computes:
1. `finalTaskSuccessRate` — strict end-to-end pass rate (`passed && !hardVetoed && hiddenAcceptancePassed`).
2. `rootCauseAccuracy` — share of trials modifying true root-cause files and passing hidden validation (rejecting surface symptom patches).
3. `firstFixSuccessRate` — share passing on initial fix attempt without repair rounds or retries.
4. `regressionTestPassRate` — share with untampered baseline tests and zero exit on baseline + public suites.
5. `ineffectiveActionCount` — cumulative wasted/rejected/thrashing actions across trials.
6. `replanEffectivenessRate` — recovery success rate among trials that triggered replanning/repair.
7. `tokenCost` — total input + output token cost across all trials (with per-trial breakdown).
8. `meanDurationMs` — mean trial wall-clock duration in milliseconds.
9. `recoverySuccessRate` — success rate on crash/interruption recovery tasks (`ar-08`).

Every failed trial is attributed deterministically into one of three root buckets (`none` when passed):
- **`tool_mechanism`**: policy/approval denials (`POLICY_DENIED`, `APPROVAL_DENIED`), tool schema errors, sandbox policy violations, dependency violations, or missing tool execution receipts.
- **`runtime_reliability`**: timeouts, cancellations, `STEP_BUDGET_EXHAUSTED`, `LOOP_THRASHING_ABORT`, `LEASE_LOST`, `RECONCILIATION_REQUIRED`, `STALE_VERIFICATION_AFTER_EDIT`, `UNRESOLVED_VERIFICATION_FAILURE`, `EVIDENCE_INCOMPLETE`, or infra faults.
- **`model_capability`**: semantic defects with healthy tools and reliable runtime (`surface_symptom_patch`, `hidden_acceptance_failed`, `implementation_failed`, `constraint_dropped`, `baseline_tests_tampered`).

### 4.3 Paired A/B Execution (`benchmark-autonomous-reasoning.mjs`)

- **`--mode deterministic`**: dynamically probes baseline (`b50da9b`) vs candidate worktrees (gracefully handling absent 2.4 modules on `b50da9b`), exercises `AgentLoop`, `EvidenceVerifier`, `MultiStageCompactor`/`compactTwoStage`, `AdaptiveReplanner`, and `ExperienceMemoryService`, and scores every workspace with real Docker `runHiddenAcceptance`.
- **`--mode real`**: executes paired AB/BA evaluation against authorized HTTPS or loopback endpoints using `TI_BENCH_KEY` / `AGENT_US_BENCH_KEY` scrubbed from child environments and redacted with `redactSecrets` (never touching `backend/var/`).
